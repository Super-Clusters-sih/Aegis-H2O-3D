# Aegis H2O — Filter 3D Model

## 💧 Overview

This repository contains the **3D Blender model of the filtration section of the Aegis H2O system**.

The model focuses specifically on the filter assembly and its physical design, providing a separate visualization of the filtration component used within the overall Aegis H2O concept.

## 🎯 Purpose

The filter 3D model is intended to help with:

- Filtration system visualization
- Mechanical design planning
- Filter assembly development
- Hardware integration
- Prototype fabrication
- Project demonstrations

## 🧊 3D Model

The model was created using **Blender**.
